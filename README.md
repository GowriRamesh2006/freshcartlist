# FreshCart: Your Green Grocery Planner

Create a complete responsive Grocery List Website named "FreshCart" for a college project.

Use React, TypeScript, Tailwind CSS and localStorage. No backend, API, login or unnecessary features.

DESIGN:

Nature Organic grocery theme with an attractive pastel green-to-cream gradient background:

#E8F5E9 → #FFF8E7

Use #81C784 accents and #2E7D32 headings.

Add soft floating leaf/circle decorations, grocery illustrations, white rounded cards, soft shadows and modern typography.

ANIMATIONS:

Add clearly visible but smooth animations:

page fade-in, hero slide-up, floating grocery illustration, button hover/scale, card hover, category hover, and smooth add/delete/purchased transitions.

PAGES:

Home, Grocery List, About.

HOME:

Hero: "Plan Your Shopping Easily", short description, animated grocery illustration, Start Shopping button, feature cards and grocery categories.

GROCERY LIST:

Show Total/Purchased/Pending counts, Add Item, Search, Category/Status filters and attractive item cards.

ITEMS:

Name, Quantity, Unit, Category, Notes, Purchased checkbox, Edit and Delete.

FUNCTIONS:

Add, Edit, Delete, Purchase/Unpurchase, Search, Filter and localStorage saving.

CATEGORIES:

Fruits, Vegetables, Dairy, Grains, Snacks, Beverages, Household, Other.

Make every button functional, mobile responsive and polished. Include About section and Footer. Ensure the gradient background, decorations and animations are clearly visible.
